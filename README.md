# SamSpring Homebrew tap

Homebrew support for [SpaceBar](https://samspring.github.io/SpaceBar-Public/) is being prepared.

**Status: not released yet.** The cask candidate is under review and still needs an isolated Homebrew installation, upgrade and removal test. No install command is published on this branch yet.

For now, use the [signed and notarized Mac download](https://samspring.github.io/SpaceBar-Public/).

This is SamSpring’s own tap. It is not part of Homebrew’s official catalogue.
